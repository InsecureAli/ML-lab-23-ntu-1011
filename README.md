## 💡 About The Repository
This repository serves as an ongoing weekly log of my practical laboratory work for my Machine Learning course at National Textile University. It tracks the step-by-step progression of my learning, from basic data preprocessing and exploratory data analysis (EDA) to training and evaluating predictive models. 

**Core concepts covered throughout the semester:**
* Data Cleaning, Feature Engineering & EDA
* Supervised Learning (Regression & Classification algorithms)
* Unsupervised Learning (Clustering & Dimensionality Reduction)
* Model Evaluation & Hyperparameter Tuning
* Fundamentals of Neural Networks
