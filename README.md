## 💡 About The Repository
This repository contains weekly laboratory tasks covering foundational and advanced machine learning concepts. It tracks the progression from data preprocessing and exploratory data analysis (EDA) to training complex predictive models and evaluating their performance. 

**Core competencies covered:**
* Data Cleaning & Feature Engineering
* Supervised Learning (Regression & Classification)
* Unsupervised Learning (Clustering & Dimensionality Reduction)
* Model Evaluation & Hyperparameter Tuning
* Neural Networks

---

## 🛠️ Technologies Used
* **Language:** Python 3.x

* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn
* **Deep Learning:** TensorFlow / Keras (Add/remove if applicable)
